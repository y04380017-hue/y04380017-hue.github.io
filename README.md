# Piko · Personal Portfolio

中文与英文个人作品集，使用静态 HTML、CSS 和 JavaScript。

网站：https://y04380017-hue.github.io/

“白日梦手作房”项目使用最终鼠标版的真实游戏截图，提供 [Windows Demo](https://github.com/y04380017-hue/daydream-handjournal/releases/tag/v0.1.0-mouse) 与 [游戏源码](https://github.com/y04380017-hue/daydream-handjournal) 入口。

本地预览可直接打开 index.html，并保持 assets 目录的相对位置。发布由 GitHub Pages 从 main 分支根目录完成；.nojekyll 用于直接提供静态文件。

项目图片、双语介绍与链接在 assets/profile-content.js 维护。字体不可用时会使用系统字体回退。
